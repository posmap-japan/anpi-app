Anpi（あんぴ）

利用規約

最終更新日: 2026年7月25日

この利用規約（以下「本規約」）は、Anpi（以下「本アプリ」）の利用に関する条件を定めるものです。本アプリをご利用いただく前に、本規約をお読みください。本アプリを利用することにより、本規約に同意したものとみなします。

第1条（サービスの概要）

本アプリは、Apple ヘルスケアの歩数・睡眠データをもとに、大切な方の安否を見守るためのサービスです。見守る人（ウォッチャー）と見守られる人（モニタード）の双方の同意に基づいて利用されます。主な機能として以下を提供します。

  • ヘルスケアの歩数・睡眠データに基づく活動確認
  • 一定時間活動が確認できない場合の自動見守り通知
  • 見守り時間の設定（1〜24時間）
  • 「大丈夫？」メッセージの送受信
  • プッシュ通知による安否アラート

第2条（収集する情報）

本アプリでは、サービスの提供に必要な最小限の情報のみを収集します。

  • ユーザーアカウント情報: 表示名、プロフィール画像（Apple ID または Google アカウントによるサインインに伴い取得）
  • ヘルスケア情報: ユーザーの許可のもと、Apple ヘルスケアから取得する歩数および睡眠データ（最終活動時刻の判定に使用）
  • ペアリング情報: 見守り関係の設定（誰が誰を見守るか、通知時間の設定）
  • プッシュ通知用のデバイストークン: Firebase Cloud Messaging（FCM）トークン

位置情報、連絡先、通話履歴、メッセージ内容、写真、ブラウザ履歴等は一切収集しません。歩数・睡眠の詳細そのものを見守り相手に共有することはなく、最終活動時刻の判定にのみ使用します。

第3条（情報の利用目的）

収集した情報は、以下の目的にのみ使用します。

  • 見守り機能の提供（歩数・睡眠に基づく活動検知と通知）
  • ユーザー認証とアカウント管理
  • サービスの維持・改善

広告目的での利用や第三者への情報販売は一切行いません。

第4条（データの保存とセキュリティ）

  1. 本アプリのデータはFirebase（Google Cloud）上に保存されます。
  2. データは暗号化された通信経路（SSL/TLS）で送受信されます。
  3. アカウントを削除した場合、関連するすべてのデータは速やかに削除されます。
  4. 決済情報（クレジットカード番号等）は本アプリでは一切取得・保存しません。決済処理はApp StoreおよびRevenueCatを通じて行われます。

第5条（ヘルスケアデータによる活動検知）

本アプリは、見守られる側のユーザーが許可した場合に限り、Apple ヘルスケアの歩数および睡眠データを読み取り、最終活動時刻を判定します。

  • 歩数の更新や睡眠データから、一定時間動き・活動があるかを判定します
  • 位置情報（GPS）は使用しません
  • ヘルスケアへのアクセスは、ユーザーが明示的に許可した場合のみ有効になります
  • 端末の電源断や通信不能などにより活動データが更新されない場合、実際には活動していても見守り通知が送られることがあります

第6条（アカウント）

  1. 本アプリの利用には、Apple ID または Google アカウントによるサインインが必要です。
  2. ユーザーは、自身のアカウント情報を適切に管理する責任を負います。
  3. アカウントの不正利用が判明した場合、当方はアカウントを停止する権利を有します。

第7条（料金プラン）

  1. 本アプリは、有料サブスクリプションプランを提供します。永続的な無料プランはありません。
  2. 各プランには、App Store上で導入オファーとして1ヶ月間の無料トライアルを設定する場合があります。無料トライアル終了後、解約していない場合は通常料金が請求されます。
  3. 有料プランの料金は以下の通りです。
    • シングルプラン: 最大1人まで（月額¥300 / 年額¥3,000）
    • ライトプラン: 最大2人まで（月額¥590 / 年額¥5,900）
    • ファミリープラン: 最大10人まで（月額¥1,480 / 年額¥14,800）
    • ビジネスプラン: 最大50人まで（月額¥5,980 / 年額¥59,800）
  4. 「見守りたい人を招待」するには、いずれかの有料プランへの登録が必要です。プランに応じた見守り人数の上限まで招待できます。
  5. サブスクリプションは自動更新されます。更新日の24時間前までに解約しない限り、自動的に更新されます。
  6. サブスクリプションの管理・解約は、App Store（iPhoneの設定 → 自分の名前 → サブスクリプション）から行えます。
  7. 購入後の返金は、Appleの返金ポリシーに従います。
