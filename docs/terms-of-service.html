Anpi（あんぴ）

利用規約

最終更新日: 2026年11月23日

この利用規約（以下「本規約」）は、Anpi（以下「本アプリ」）の利用に関する条件を定めるものです。本アプリをご利用いただく前に、本規約をお読みください。本アプリを利用することにより、本規約に同意したものとみなします。

第1条（サービスの概要）

本アプリは、Apple ヘルスケアおよびiPhoneのモーションセンサーの歩数、本アプリの操作、安否確認への回答をもとに、大切な方の安否を見守るためのサービスです。見守る人（ウォッチャー）と見守られる人（モニタード）の双方の同意に基づいて利用されます。主な機能として以下を提供します。

  • 歩数の増加、本アプリの操作、「大丈夫？」メッセージへの回答による活動確認
  • 一定時間活動が確認できない場合の、見守る人と見守られる人ご本人への通知（その後も活動が確認できない場合は、見守る人へ1時間ごとに最大3回まで再通知）
  • データが届いていない場合の、活動未確認とは区別した通知
  • 見守り時間の設定（12〜36時間。初期値は24時間）
  • 「大丈夫？」メッセージの送受信
  • プッシュ通知による安否アラート

第2条（収集する情報）

本アプリでは、サービスの提供に必要な最小限の情報のみを収集します。

  • ユーザーアカウント情報: 表示名、プロフィール画像（Apple ID または Google アカウントによるサインインに伴い取得）
  • ヘルスケア情報: ユーザーの許可のもと、Apple ヘルスケアから読み取る歩数データ（歩数が増えた時刻の確認に使用。歩数の詳細はサーバーへ送信しません）
  • モーション情報: ユーザーの許可のもと、iPhoneの「モーションとフィットネス」から読み取る歩数データ（iPhoneがロック中でも歩いた時刻を確認するために使用。歩数そのものはサーバーへ送信しません）
  • 活動に関する情報: 歩数が増えた時刻、本アプリを開いた時刻、「大丈夫？」メッセージに回答した時刻とその回答内容、データを受信した時刻
  • 動作状況: 歩数の取得状態、送信状態、バックグラウンド更新・低電力モードの状態、通知・歩数・モーションとフィットネス・バックグラウンド更新の許可状態、アプリのバージョン（データが届かない原因の把握のため）
  • ペアリング情報: 見守り関係の設定（誰が誰を見守るか、通知時間の設定）
  • プッシュ通知用のデバイストークン: Firebase Cloud Messaging（FCM）トークン

位置情報、連絡先、通話履歴、メッセージ内容、ブラウザ履歴、他のアプリの利用状況、睡眠データ等は一切収集しません。歩数の詳細そのものを見守り相手に共有することはなく、活動の確認にのみ使用します。

第3条（情報の利用目的）

収集した情報は、以下の目的にのみ使用します。

  • 見守り機能の提供（歩数・本アプリの操作・安否確認への回答に基づく活動確認と通知）
  • ユーザー認証とアカウント管理
  • サービスの維持・改善

広告目的での利用や第三者への情報販売は一切行いません。

第4条（データの保存とセキュリティ）

  1. 本アプリのデータはFirebase（Google Cloud）上に保存されます。
  2. データは暗号化された通信経路（SSL/TLS）で送受信されます。
  3. 重複防止のための活動の記録は、30日後に自動的に削除されます。
  4. アカウントを削除した場合、関連するすべてのデータは速やかに削除されます。
  5. 決済情報（クレジットカード番号等）は本アプリでは一切取得・保存しません。決済処理はApp StoreおよびRevenueCatを通じて行われます。

第5条（活動の確認方法）

本アプリは、見守られる側のユーザーについて、次のいずれかを確認したときに活動があったものとして扱います。

  • Apple ヘルスケアの歩数が増えたとき（ユーザーがヘルスケアへのアクセスを明示的に許可した場合のみ）
  • iPhoneのモーションセンサー（モーションとフィットネス）で歩数が増えたことを確認したとき（ユーザーが許可した場合のみ）
  • 本アプリを開いて操作したとき
  • 本アプリで「大丈夫？」メッセージに回答したとき（「大丈夫です」「大丈夫じゃないです」のどちらの回答でも、本人が操作したことが確認できるため活動として扱います。回答内容は見守る人に通知されます）
  • 見守りは、見守られる人の端末で通知・歩数・モーションとフィットネス・Appのバックグラウンド更新が許可され、見守る人の端末で通知が許可されてから始まります
  • 位置情報（GPS）は使用しません。他のアプリの利用状況や睡眠データは、活動の確認に使用しません
  • 歩数が送信されるタイミングは、端末の状態（電源、通信、低電力モード、バックグラウンド更新の設定等）によって遅れることがあります
  • 端末の電源断や通信不能などによりデータが届かない場合は「データが届いていません」として通知します。実際には活動していても通知が送られることがあります
  • 本アプリは、通常の休息と体調不良等を医学的に区別するものではありません

  2. ユーザーは、自身のアカウント情報を適切に管理する責任を負います。
  3. アカウントの不正利用が判明した場合、当方はアカウントを停止する権利を有します。

第7条（料金プラン）

  1. 本アプリは、基本的な見守りを利用できる無料のFreeプランと、有料サブスクリプションプランを提供します。
  2. 有料プランには、App Store上で導入オファーとして1ヶ月間の無料トライアルを設定する場合があります。無料トライアル終了後、解約していない場合は通常料金が請求されます。
  3. プラン構成は以下の通りです。人数は「見守られる人」の上限を指し、通知を受け取るご家族の人数とは異なります。
    • Free: 最大1人まで（無料）
    • Plus: 最大2人まで（月額¥300 / 年額¥3,000）
    • Family: 最大5人まで（月額¥1,480 / 年額¥14,800）
    • Business: 最大50人まで（月額¥5,980 / 年額¥59,800）
  4. Freeでも1人を招待して見守れます。各プランの上限は新規追加時に適用され、上限を超える既存ペアリングは自動解除されません。有料プランはPlus・Family・Businessの有効な契約に基づいて提供します。購入時の価格・請求条件はApp Storeの表示に従います。
  5. サブスクリプションは自動更新されます。更新日の24時間前までに解約しない限り、自動的に更新されます。
  6. サブスクリプションの管理・解約は、App Store（iPhoneの設定 → 自分の名前 → サブスクリプション）から行えます。
  7. 購入後の返金は、Appleの返金ポリシーに従います。
